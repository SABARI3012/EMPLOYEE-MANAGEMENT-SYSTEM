To create the Angular 16 project as described, follow these steps:

1. Create the Angular Project:
Open your terminal, and create a new Angular 16 project named "FAM" by running the following commands:

bash
Copy

ng new fam
cd fam

During the creation, you'll be prompted for configurations like routing and stylesheet format. Choose the defaults or as per your preference.

2. Install Dependencies:
To manage data in JSON format, we can use a simple Angular service. However, for storage purposes (like persisting data in a simple structure), we can use a mock JSON file.

Since Angular doesn't use any backend, we'll handle data within the service (mock JSON).

3. Generate Components:
We'll need four components: Home, Grocery List, Expense Tracker, Wishlist, and Plans. Use the Angular CLI to generate these:

bash
Copy

ng generate component home
ng generate component grocery-list
ng generate component expense-tracker
ng generate component wishlist
ng generate component plans

6. Set Up the JSON Service:
Now, let's set up a simple service to handle data storage (in a mock JSON-like structure).

Create a service to manage all your data:

bash
Copy
ng generate service data
In src/app/data.service.ts:

typescript
Copy
import { Injectable } from '@angular/core';

@Injectable({
  providedIn: 'root'
})
export class DataService {
  private groceryList: any[] = [];
  private expenseList: any[] = [];
  private wishlist: any[] = [];
  private plans: any[] = [];

  constructor() {}

  // Grocery List methods
  getGroceryList() {
    return this.groceryList;
  }

  addGrocery(item: any) {
    this.groceryList.push(item);
  }

  deleteGrocery(index: number) {
    this.groceryList.splice(index, 1);
  }

  deleteAllGroceries() {
    this.groceryList = [];
  }

  // Expense Tracker methods
  getExpenses() {
    return this.expenseList;
  }

  addExpense(expense: any) {
    this.expenseList.push(expense);
  }

  deleteExpense(index: number) {
    this.expenseList.splice(index, 1);
  }

  deleteAllExpenses() {
    this.expenseList = [];
  }

  // Wishlist methods
  getWishlist() {
    return this.wishlist;
  }

  addToWishlist(item: any) {
    this.wishlist.push(item);
  }

  deleteFromWishlist(index: number) {
    this.wishlist.splice(index, 1);
  }

  deleteAllWishlist() {
    this.wishlist = [];
  }

  // Plans methods
  getPlans() {
    return this.plans;
  }

  addPlan(plan: any) {
    this.plans.push(plan);
  }

  deletePlan(index: number) {
    this.plans.splice(index, 1);
  }

  deleteAllPlans() {
    this.plans = [];
  }
}
7. Grocery List Page:
In src/app/grocery-list/grocery-list.component.ts, define the logic for adding and removing items:

typescript
Copy
import { Component } from '@angular/core';
import { DataService } from '../data.service';

@Component({
  selector: 'app-grocery-list',
  templateUrl: './grocery-list.component.html',
  styleUrls: ['./grocery-list.component.css']
})
export class GroceryListComponent {
  groceryName = '';
  groceryQuantity = '';
  groceryList = this.dataService.getGroceryList();

  constructor(private dataService: DataService) {}

  addItem() {
    if (this.groceryName && this.groceryQuantity) {
      this.dataService.addGrocery({
        name: this.groceryName,
        quantity: this.groceryQuantity
      });
      this.groceryName = '';
      this.groceryQuantity = '';
    }
  }

  deleteItem(index: number) {
    this.dataService.deleteGrocery(index);
  }

  deleteAll() {
    this.dataService.deleteAllGroceries();
  }
}
